## 2. 잘된 점

- **요청을 작게 나눠 바로 확인했다.** 기능 하나를 요청하면 브라우저에서 바로 띄워 보고, 다음 요청으로 넘어갔다. 방향이 틀어지기 전에 고칠 수 있었다.
- **점수 규칙은 "직접 만든 보드"로 검증했다.** 손으로 플레이해서는 T-스핀 더블이나 퍼펙트 클리어를 일부러 만들기 어렵다. 그래서 보드를 코드로 쌓아 놓고 놓아 보는 방식으로 확인했다.

  | 상황 | 기대 | 결과 |
  |---|---|---|
  | 레벨 0, T-스핀 더블 | 1,200점 | 1,200점, `T-SPIN / DOUBLE` 표시 |
  | 이어서 테트리스로 보드를 비움 | 800×1.5 + 콤보 50 + 퍼펙트 2,000 = 3,250점 | 3,250점, `BACK2BACK / 1 COMBO / PERFECT` 표시 |
  | 바닥에서 2초 동안 계속 회전 (인피니티) | 고정되지 않음 | 고정되지 않음 |
  | 스테이지 3 목표 달성 | 보너스 8,100점, 스테이지 4(목표 10줄)로 이동 | 그대로 동작 |
  | 스테이지 20 클리어 | ALL STAGES CLEAR 엔딩 | 그대로 동작 |

- **배포까지 한 흐름으로 했다.** GitHub CLI 설치 → 로그인 → 커밋·푸시 → GitHub Pages 켜기 → 실제 링크에서 다시 확인까지 마쳤다.
- **테스트 모드를 따로 만들었다.** 댄서 연출을 보려고 매번 7줄 이상 지울 수 없어서, 타이틀에서 **T**(또는 주소 끝 `?test`)로 켜고 **K**로 스테이지를 바로 클리어하게 했다. 확인 시간이 크게 줄었다.

## 4. 저작권 문제로 바꾼 것

- 1988년 텡겐판의 **LOGINSKA, BRADINSKY, TROIKA**는 그 게임을 위해 작곡된 곡이고, **KARINKA**는 민요를 텡겐 쪽에서 편곡한 버전이다. 회사 저작물은 공표 후 수십 년(한국 70년, 미국 95년) 보호되므로, 공개 사이트에 올리는 게임에서 선율을 따라 만들 수 없었다.
- 대신 이렇게 했다.
  - **KOROBEINIKI, KALINKA**: 저작권이 끝난 러시아 민요를 직접 편곡
  - **TROIKA, VOLGA, MATRYOSHKA, KAZACHOK**: 러시아풍 창작곡 (TROIKA는 이름만 같고 텡겐판과 다른 곡)
  - 선율은 그대로 두고 **음색과 편곡만** 텡겐 NES풍으로: 펄스 듀티 교대, 비브라토, 에코, 계단식 삼각파 베이스, LFSR 노이즈 드럼, 섹션 끝 필인
- 배운 점: "옛날 게임이니까 괜찮겠지"는 틀렸다. 게임 음악은 아직 보호 기간 안에 있는 경우가 많고, 칩튠으로 다시 만들어도 같은 선율이면 편곡에 해당한다.

## 5. 아쉬운 점 / 확인하지 못한 것

- **소리는 에이전트가 들을 수 없었다.** 6곡과 효과음이 오류 없이 재생되는 것까지만 확인했고, 실제로 듣기 좋은지는 직접 들어보고 판단해야 한다.
- **KALINKA 선율은 악보 없이 기억으로 옮겼다.** 앞부분("칼린카, 칼린카…")은 맞지만 뒷부분은 원곡과 다를 수 있다. 악보를 구해 대조할 필요가 있다.
- **스테이지 난이도는 숫자로만 정했다.** 목표 줄 수, 방해 블록 높이, 속도를 공식으로 정했을 뿐 직접 끝까지 플레이해 보지 않았다.
- **AI 데모는 단순하다.** 높이·구멍·울퉁불퉁함 점수로 자리만 고르고, T-스핀 같은 기술은 쓰지 않는다.
- **커밋이 크다.** 3단계 전체(스테이지, 음악 6곡, 댄서, Я, 음색)가 커밋 하나에 들어가 변경 과정을 따라가기 어렵다. 다음에는 기능 단위로 나눠 커밋한다.
