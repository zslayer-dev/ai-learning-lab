# Run Log Analyzer Skill (`run-log-analyzer`)

러닝 기록(거리, 페이스, 심박수, 고도 등)을 분석할 때 매번 개인 심박수 기준, 측정 장비, 주로 뛰는 코스의 고도 특성을 다시 설명해야 하는 번거로움을 없애주는 개인 맞춤형 러닝 분석 스킬입니다.

## 1. 왜 만들었는가 (불편함과 해결)

### 기존의 불편함 (재프롬프트 문제)
러닝이 끝난 뒤 AI에게 기록 분석을 맡길 때마다 세 가지를 매번 설명하거나 바로잡아야 했습니다.

1. **심박수 기준**: AI가 나이 기반 공식(220 − 나이)으로 구간을 잡아서, 실제 수치(최대 202bpm, 안정시 60bpm)와 카르보넨 기준 Zone 2(145~159bpm)를 다시 알려줘야 했습니다.
2. **측정 장비**: 대회나 언덕 훈련에서 심박수가 높게 나오면 AI가 습관적으로 "손목 광학 센서의 케이던스 락(오류)일 수 있다"고 추측해서, "가슴 심박계로 측정한 실제 수치"라고 매번 정정해야 했습니다.
3. **코스 지형**: 자주 뛰는 9km 고개 코스(±233m)를 보고 AI가 "오르막과 내리막이 반복되는 코스"라고 해석해서, "꾸준히 오르막을 오른 뒤 정상부터 계속 내리막으로 내려오는 구조"라고 반복해서 바로잡아야 했습니다.

### 스킬을 통한 해결
심박수 구간(카르보넨), 장비 특성(가슴 심박계, 케이던스 락 배제), 주요 코스의 지형 구조와 판별 기준을 `SKILL.md`에 고정했습니다. 이제 새 대화에서 러닝 기록만 주면 배경 설명 없이 바로 훈련 피드백을 받을 수 있습니다.

## 3. 설치 방법

### Claude Code
적용할 프로젝트(또는 작업 폴더) 루트에서 스킬 폴더를 복사합니다.

```bash
mkdir -p .claude/skills
cp -r /path/to/ai-learning-lab/assignments/run-log-analyzer-skill/.claude/skills/run-log-analyzer ./.claude/skills/
```

처음 스킬 폴더를 만들었다면 Claude Code를 재시작해야 인식됩니다.

### claude.ai
`run-log-analyzer` 폴더를 zip으로 묶어 claude.ai 설정의 Skills에서 업로드한 뒤 켜면 됩니다. (유료 플랜, 코드 실행 기능 필요)

## 4. 호출 방법

새 대화에서 러닝 기록을 붙여넣고 이렇게 요청합니다.

> 오늘 러닝 기록 분석해줘
> 거리 9.1km, 평균 페이스 6:12/km, 평균 심박 158, 최대 심박 176, 누적 상승 231m

스킬 이름을 직접 부르지 않아도 description에 맞는 요청이면 자동으로 발동됩니다.

## 6. 다른 사람이 쓸 때

`SKILL.md`의 심박수(최대·안정시)와 코스 정보를 본인 값으로 바꾸면 그대로 쓸 수 있습니다. Zone 표는 카르보넨 공식(RHR + (MaxHR − RHR) × 강도)으로 다시 계산하면 됩니다.
