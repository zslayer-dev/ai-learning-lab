# 자기 도메인 업무 분해 — 대화형 콘텐츠 수치 조정

## [도메인 맥락]
나는 게임 클라이언트 프로그래밍 도메인 19년 차이고, 언리얼 엔진 프로젝트에서 기획자가 대화로 콘텐츠 수치를 직접 조정하고 테스트하는 작업을 자동화하고 싶습니다.

## [네 동작 분석]
1. **분해**: 콘텐츠 구현, 조정할 수치 정의, 기획 용어와 실제 필드 연결, 대화형 입력, 변경 전후 확인, 적용 및 테스트로 나눕니다.
2. **패턴**: 데미지·쿨다운·연사속도처럼 콘텐츠마다 반복되는 수치가 있고, "10% 올려줘", "전부 같게 맞춰줘" 같은 조정 방식도 반복됩니다. 이 둘을 찾아 공통화합니다.
3. **추상화**: 대화로 들어온 요청은 결국 "어느 항목의 어느 값을 얼마로 바꾸는가" 하나로 정리됩니다. 대화는 수치 초안을 빠르게 잡는 용도이고, 결과는 DataTable에 그대로 남겨 세부 조정은 기획자가 직접 합니다.
4. **알고리즘**: 조정 항목 정의 → 대화로 값 입력 → 변경 전후 표시 → 기획자 승인 → 적용 → PIE에서 결과 확인 순서로 진행합니다.

## [출력 요구]
기획자가 프로그래밍 지식 없이 대화로 콘텐츠 수치를 바꾸고 결과를 확인할 수 있는 도구의 설계안을, 마크다운 문서 형식으로, 한국어로.

## [검증 기준]
기획자 한 사람이 설계안을 보고 "개발자 도움 없이 수치를 바꾸고 결과를 확인할 수 있겠다"고 평가하고,
언리얼 엔진 개발자 한 사람이 "변경값이 의도한 콘텐츠에만 적용되고 기존 콘텐츠에 영향이 없다"고 평가할 것.
